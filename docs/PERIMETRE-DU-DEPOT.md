# Périmètre du dépôt de revue

Application actuelle dans `application/`, références S00 et visuelles dans les autres dossiers. Sources et tests conservés ; captures historiques de `application/preuves/`, anciens ZIP, environnements installés, bases, secrets, sessions et sauvegardes privées exclus. Les liens historiques vers les captures absentes sont conservés comme références, sans prétendre que ces pièces sont embarquées. Le package global de revue précédent reste la source des captures historiques.

Le dossier historique `prototype-evolution/` n’est pas nécessaire à l’exécution et reste dans le package global précédent. Aucun historique Git ni auteur de commit n’est fabriqué. Les binaires de test audio/documents et polices nécessaires restent inclus.

L’archive n’est pas une sauvegarde de données ni un déploiement autonome. Les scripts d’intégration utilisent des services/comptes locaux non embarqués. Ne pas exécuter leurs mutations en production.

Aucune licence générale nouvelle n’a été attribuée. Les licences des dépendances et polices sont conservées. Dépôt privé conseillé tant que le propriétaire n’a pas choisi les conditions de diffusion.
