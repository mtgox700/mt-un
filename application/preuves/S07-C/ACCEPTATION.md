# S07 C — critères et preuves

- Dépôt depuis le bouton Joindre : message et objet uniques, scan réel, état persistant, reprise explicite sans écrasement.
- Quarantaine : EICAR bloqué, interruption de scan fermée, génération périmée refusée, reprise réelle.
- Contrôles cumulés : MFA, appartenance, module et commercial, permission, période/historique du message, téléchargement distinct.
- Dossiers : référence durable de message ou pièce, aucune copie du contenu source ; droits source/destination vérifiés à chaque accès.
- Corbeille source : demande, validation super admin sans contenu, retrait effectif des fichiers et références, restauration sans restituer les droits révoqués.
- Interface : auteur et lecteur, dépôt/aperçu/classement/téléchargement/refus, viewports mobile/tablette/desktop.
- Régressions A/B/coffre/classement Agenda ; intégrité de S00/prototype ; aucun secret dans les preuves.
