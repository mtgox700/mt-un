S02 · Frontal compilé et séparation de logique

26 octobre 2026 — Ouvrir le frontal compilé local.

Livré

  • Chaîne de build locale esbuild, dépendances fixées et package-lock.json.
  • React 18.3.1 et ReactDOM inclus dans le bundle local : plus de chargement de React depuis le CDN.
  • 16 méthodes séparées par analyse syntaxique : thème (8), dossiers (4), contacts (2), navigation (2). Le build vérifie le réassemblage strictement identique à la logique source avant compilation.
  • La logique est compilée dans dist/application.js. Le runtime de compatibilité utilise une fabrique statique ; les constructions dynamiques de JavaScript et imports de code arbitraire sont désactivés dans ce lot.
  • Les quatre vues séparées et le thème restent inchangés.

Le moteur d’interprétation des templates reste conservé. Les méthodes sont séparées à la source puis assemblées dans le composant de compatibilité : elles ne sont pas encore des modules métier autonomes avec état et dépendances indépendants. Les variables communes et le rendu global restent dans logic/shared.jsfrag. Les polices restent chargées par le mécanisme de référence.

Recette

12 comparaisons avec le premier lot S02 non compilé : accueil, dossiers, détail et contacts à 390, 820 et 1440 pixels. Largeur réelle vérifiée. Textes, dimensions, polices et couleurs des titres, boutons et champs mesurés identiques ; aucun débordement horizontal global. Ce contrôle n’est pas un diff pixel exhaustif de toutes les zones.

Trois parcours dossiers → détail → retour réussis, un par format. Les animations ont nécessité une observation stabilisée ; les écarts transitoires ne sont pas considérés comme des changements de design. 834 empreintes du prototype et de S00 inchangées.

Commandes

Depuis application/frontend avec Node et npm disponibles : npm ci puis npm run build. Depuis application avec Python : python3 -B -m uniion.frontend (port 5063, boucle locale seulement). Le script split-logic.mjs est un outil d’extraction initiale : ne pas le relancer sur des modules modifiés sans revue, car il les réécrit depuis la référence.

Reste pour S02

  1. Remplacer le composant partagé par des modules indépendants et un registre de routes/contrats définitif ; extraire le reste des vues.
  2. Raccorder les sessions, organisations, permissions et activations des modules au serveur S01. L’hôte actuel reste une démonstration fictive sans API métier.
  3. Porter les écrans complémentaires de la copie organisation/droits/partage et leurs parcours.
  4. Compléter les comparaisons visuelles, modales, notifications, clavier et erreurs ; tester les refus des modules désactivés par URL/API.
  5. Retirer le moteur de templates de compatibilité et empaqueter les dépendances visuelles restantes avant qualification du frontal final.

Aucun déploiement ; S02 reste en cours. La compilation est acquise pour le lot de compatibilité, pas pour la totalité de l’architecture finale.
